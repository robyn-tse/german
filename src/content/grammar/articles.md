## The three articles

German has three definite articles: **der** for masculine nouns (Maskulinum), **die** for feminine nouns (Femininum) and **das** for neuter nouns (Neutrum). Native speakers know the article intuitively; learners mostly have to memorise it, because there are only a few rules. Always learn a noun together with its article.

**Plural is always die**, regardless of the singular gender: die Männer, die Frauen, die Häuser.

## Rules for der (masculine)

| Category | Examples |
|---|---|
| Male people and professions | der Vater, der Bäcker, der Juwelier |
| Seasons | der Frühling, der Herbst |
| Months | der Juli, der August |
| Days of the week | der Samstag, der Sonntag |
| Compass directions | der Norden, der Osten |
| Weather | der Regen, der Blitz |
| Car brands | der Nissan, der Honda |
| Trains | der IC, der Regionalexpress |
| Alcoholic drinks | der Cognac, der Wein |
| Nouns formed from verbs without an ending (rare) | der Gesang, der Fang, der Abbruch |

Suffixes that point to **der**:

| Suffix | Examples |
|---|---|
| -er | der Rentner, der Drucker, der Computer |
| -ling | der Schützling, der Schmetterling |
| -or | der Reaktor, der Professor |
| -ist | der Journalist, der Pazifist |
| -ismus | der Kapitalismus, der Mechanismus |

## Rules for die (feminine)

| Category | Examples |
|---|---|
| Motorcycle brands | die Suzuki, die Triumph |
| Ship names | die Gorch Fock, die Europa |
| Aeroplanes | die Boeing, die Concorde |
| Numbers | die Eins, die Zwei, die Drei |
| Flowers | die Rose, die Tulpe, die Hyazinthe |

Suffixes that point to **die**:

| Suffix | Examples |
|---|---|
| -e | die Tasche, die Ente, die Lampe, die Sprache |
| -t | die Fahrt, die Tat, die Nacht |
| -ei | die Wäscherei, die Bäckerei |
| -ie | die Psychologie, die Arterie |
| -in | die Prinzessin, die Ärztin |
| -schaft | die Freundschaft, die Mannschaft, die Wirtschaft |
| -heit / -keit | die Gelegenheit, die Schnelligkeit, die Freiheit, die Möglichkeit |
| -ung | die Zeitung, die Umleitung, die Wohnung |

Endings of foreign words that point to **die**:

| Suffix | Examples |
|---|---|
| -ion | die Diskussion, die Tradition, die Nation |
| -age | die Garage, die Passage |
| -ur | die Agentur, die Manufaktur |
| -ik | die Physik, die Metrik |
| -anz | die Akzeptanz, die Ignoranz |
| -tät | die Qualität, die Fakultät |
| -ade | die Parade, die Marmelade |
| -enz | die Präsenz, die Tendenz |

## Rules for das (neuter)

| Category | Examples |
|---|---|
| Adjectives used as nouns | das Schöne, das Gute |
| Verbs used as nouns | das Schreiben, das Tippen |
| Colour names | das Grün, das Rot, das Gelb |
| Chemical elements | das Wolfram, das Uran |
| Metals | das Aluminium, das Eisen |

Suffixes that point to **das**:

| Suffix | Examples |
|---|---|
| -chen (diminutive) | das Mädchen, das Heftchen |
| -lein (diminutive) | das Kindlein, das Bächlein |
| -um | das Publikum, das Zentrum |
| -nis | das Zeugnis, das Ergebnis |
| -tum | das Altertum, das Datum |
| -ment | das Instrument, das Parlament |
| -o | das Radio, das Kino, das Auto |

Nouns with the prefix **Ge-** are often neuter: das Gehölz, das Geflügel, das Gemüse (collectives); das Geräusch, das Gestöber, das Gebet, das Gerüst (abstract nouns from verbs).

> These rules hold for most words in each category, but there are exceptions (der Name, der Junge, das Auge all end in -e). That is why it matters to learn every noun together with its article from the start.

## Definite and indefinite

| | masculine | feminine | neuter | plural |
|---|---|---|---|---|
| definite (bestimmt) | der | die | das | die |
| indefinite (unbestimmt) | ein | eine | ein | – (no article) or die |

Something is introduced with **ein/eine** and referred back to with **der/die/das**: *Da vorne ist **eine** Bäckerei. **Die** Bäckerei hat gute Brötchen.* In the plural there is no indefinite article, only nothing (*Nullartikel*) or **die**: *Da sind [–] Kinder. **Die** Kinder spielen.*

Watch out: when a masculine noun is the *object* of the sentence, **ein** becomes **einen** (*Er trinkt **einen** Saft*, *Ich brauche **einen** Stift*). That is the accusative case (see *Declension*).
