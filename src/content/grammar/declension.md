## The four cases

| | masculine | feminine | neuter | plural |
|---|---|---|---|---|
| **Nominativ** | der / ein / kein | die / eine / keine | das / ein / kein | die / – / keine |
| **Akkusativ** | den / einen / keinen | die / eine / keine | das / ein / kein | die / – / keine |
| **Dativ** | dem / einem / keinem | der / einer / keiner | dem / einem / keinem | den / – / keinen |
| **Genitiv** | des / eines / keines | der / einer / keiner | des / eines / keines | der / – / keiner |

**Genitiv: the noun changes too.** Masculine and neuter nouns take **-s** or **-es**: **-es** for short one-syllable nouns and nouns ending in -s, -ß, -z, -x or -sch (des Mann**es**, des Kind**es**, des Haus**es**), **-s** for most others (des Lehrer**s**, des Auto**s**). Feminine and plural nouns do not change (der Frau, der Familien).


## Dativ

*Ich gebe **dem** Mann das Buch. Sie schenkt **der** Frau einen Ring. Sie erklärt **den** Schülern die Regeln.*

Verbs with the dative: **helfen, danken, folgen, vertrauen, antworten, gehören, glauben, gratulieren**. *Ich helfe dem Mann. Der Hund gehört der Familie. Sie gratuliert der Schwester.*

## Akkusativ

*Ich sehe **den** Mann. Sie kauft **die** Tasche. Er liest **das** Buch. Ich kaufe **einen** Regenschirm. Sie braucht **eine** Einladung.* *Wir sammeln Informationen.*
