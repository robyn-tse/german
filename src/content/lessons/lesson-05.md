## The preposition decides the case

Once a preposition is present, the case is fixed, whatever the verb.

### Always Dativ

| | | Example |
|---|---|---|
| ab | from | |
| außer | except for, besides | |
| **zu** | to (toward a person or place) | Ich gehe **zu der** Oma. |
| **nach** | to (cities and countries only), after (time) | Ich fahre **nach** Berlin. / **nach** Afrika. |
| **bei** | at, near, with (at someone's place) | Ich bin **bei der** Oma. |
| von | from, of | |
| aus | from (origin), out of, made of | |
| mit | with | Ich gehe **mit dem** Hund. |
| seit | since | Sie wohnen **seit** Jahren in der Schweiz. |
| gegenüber | opposite, across from | |

Most important to start: **zu, bei, nach**.

### Always Akkusativ

| | | Example |
|---|---|---|
| bis | until | |
| durch | through | |
| für | for | |
| ohne | without | Ich gehe **ohne den** Hund. |
| gegen | against | |
| um | around, at (time) | |

### Wechselpräpositionen: Dativ or Akkusativ

in, an, auf, neben, hinter, über, unter, vor, zwischen

| | | |
|---|---|---|
| in | in, into | über | over, above, about |
| an | on (vertical), at, by (rivers, coasts) | unter | under, below |
| auf | on (horizontal) | vor | in front of, before (time) |
| neben | next to, beside | zwischen | between |
| hinter | behind | | |

| Question | Verb | Case |
|---|---|---|
| **Wo?** (where?) | static, no movement | **Dativ** |
| **Wohin?** (where to?) | movement from A to B | **Akkusativ** |

| | Wo? → Dativ | Wohin? → Akkusativ |
|---|---|---|
| der Kasten | in **dem** Kasten | in **den** Kasten |
| die Lade | in **der** Lade | in **die** Lade |
| das Regal | in **dem** Regal | in **das** Regal |
| die Mappen | in **den** Mappen | in **die** Mappen |

| Bewegung → Akkusativ | keine Bewegung → Dativ |
|---|---|
| setzen, stellen, legen | liegen, stehen, sitzen |
| sich setzen (to sit down): Setz dich bitte in **den** Sessel. | verstecken (to hide) |
| | spielen: Die Kinder spielen **im** Garten. |

- **auf** = horizontal surfaces (das Dach). **an** = vertical surfaces and the water side: lake, sea, river (die Wand).
- Die Schweiz takes **in**, not nach: Sie reisen **in die** Schweiz.

### Short forms

| | |
|---|---|
| in dem → **im** | in das → **ins** |
| an dem → **am** | an das → **ans** |
| zu dem → **zum** | zu der → **zur** |
| bei dem → **beim** | von dem → **vom** |

## Examples from the lesson

| | | |
|---|---|---|
| Ich gehe in **den** Garten. | I go into the garden. | wohin? → Akkusativ |
| Ich bin in **dem** Garten. / **im** Garten. | I am in the garden. | wo? → Dativ |
| Wir gehen heute Abend **ins** Kino. | We are going to the cinema tonight. | wohin? → Akkusativ (in das → ins) |
| Die Kinder spielen **im** Garten. | The children are playing in the garden. | spielen is not A-to-B movement → Dativ |
| Er hängt das Bild an **die** Wand. | He hangs the picture on the wall. | hanging it there → Akkusativ |
| Das Bild hängt jetzt an **der** Wand. | The picture now hangs on the wall. | it hangs there → Dativ |
| Setz dich bitte in **den** Sessel. | Please sit down in the armchair. | sich setzen = movement → Akkusativ |
| Opa schläft **im** Sessel. | Grandpa is sleeping in the armchair. | static → Dativ |
| Sie reisen in **die** Schweiz. | They travel to Switzerland. | movement → Akkusativ |
| Sie wohnen seit Jahren in **der** Schweiz. | They have lived in Switzerland for years. | wohnen = static → Dativ |
| Ich sitze vor **dem** Haus. | I am sitting in front of the house. | wo? → Dativ |
| Ich laufe in **den** Garten. | I run into the garden. | wohin? → Akkusativ |
| Ich schwimme vor **das** Boot. | I swim in front of the boat. | wohin? → Akkusativ |
| Ich bin zwischen **den** Palmen. | I am between the palm trees. | wo? → Dativ (plural: den) |
| Ich bin auf **der** Spitze **des** Berges. | I am on the top of the mountain. | wo? → Dativ; des Berges = Genitiv |
| Ich schicke **dem** Mann das Buch. | I send the man the book. | dative verb, no preposition |

## Genitiv

- **des Berges** = of the mountain. Masculine and neuter nouns add **-s** or **-es**: des Mann**es**, des Haus**es**.
- Feminine singular: **der** (der Frau). Plural: **der** (der Eltern, der Häuser).
