## Present tense

| | | ending | kaufen (to buy) | haben (to have) | sein (to be) |
|---|---|---|---|---|---|
| I | ich | **-e** | kauf**e** | habe | bin |
| you | du | **-st** | kauf**st** | hast | bist |
| he / she / it | er / sie / es | **-t** | kauf**t** | hat | ist |
| we | wir | **-en** | kauf**en** | haben | sind |
| you all | ihr | **-t** | kauf**t** | habt | seid |
| they / you (formal) | sie / Sie | **-en** | kauf**en** | haben | sind |

- About 80 % of verbs are weak: strip **-en**, add the ending. **haben** and **sein** are irregular.
- **Sie** (capital S) is formal "you" and takes the plural form.
- Verbs in **-eln** drop the *e* in the ich-form: ich entwick**le**, ich verhand**le**.

## Separable prefixes

The verb takes second position; the prefix goes to the **end** of the sentence. *Ich räume das Zimmer **auf**.*

| Prefix | Verb | Example |
|---|---|---|
| ab- | abfahren (to depart) | Ich fahre ab. |
| an- | anfangen (to begin) | Ich fange an. |
| auf- | aufräumen (to tidy up) | Ich räume auf. |
| aus- | ausgehen (to go out) | Ich gehe aus. |
| bei- | beistehen (to stand by) | Ich stehe bei. |
| ein- | einkaufen (to shop) | Ich kaufe ein. |
| mit- | mitkommen (to come along) | Ich komme mit. |
| nach- | nachfragen (to ask again) | Ich frage nach. |
| vor- | vorstellen (to introduce) | Ich stelle vor. |
| weg- | weggehen (to go away) | Ich gehe weg. |
| her- | herkommen (to come here) | Komm her, ich muss dir etwas zeigen! |
| hin- | hinbringen (to bring there) | Ahmad bringt den Kuchen morgen hin. |
| hinein- | hineingehen (to go in) | Möchtest du hineingehen oder lieber draußen sitzen? |
| los- | losgehen (to set off) | Wir werden um 20 Uhr losgehen, kommst du mit? |
| zu- | zumachen (to close) | Machst du bitte das Fenster zu? Mir ist kalt! |
| zurück- | zurückgeben (to give back) | Kannst du mir bitte meinen Stift zurückgeben? |
| um- | umsetzen (to implement) | Nach dem Closing setzen die Teams die Integrationsstrategie um. |
| fern- | fernsehen (to watch TV) | Am Abend sehen wir oft fern. |
| kennen- | kennenlernen (to get to know) | Wir lernen heute neue Wörter kennen. |
| sauber- | saubermachen (to clean) | Der Lehrer macht die Tafel sauber. |
| vorbei- | vorbeigehen (to go past) | |

Word order:

| | Example |
|---|---|
| statement: verb second, prefix last | Ich **stehe** um 6 Uhr **auf**. |
| yes/no question: verb first | **Kaufst** du heute **ein**? |
| with a modal verb: whole verb at the end | Ich **muss** morgen früh **aufstehen**. |

## Inseparable prefixes

Never split. *Ich **be**suche dich.* (not *Ich suche be…*)

| Prefix | Verb | Example |
|---|---|---|
| be- | besuchen | Ich besuche dich. |
| emp- | empfehlen | Ich empfehle das. |
| ent- | entscheiden | Ich entscheide mich. |
| er- | erkennen | Ich erkenne das. |
| ge- | gehören | Das gehört mir. |
| miss- | missverstehen | Ich missverstehe dich. |
| ver- | verstehen | Ich verstehe dich. |
| zer- | zerstören | Ich zerstöre das. |

## Partizip II with a prefix

| | Rule | Example |
|---|---|---|
| separable | **ge-** between prefix and stem | aufräumen → ich habe **aufgeräumt** |
| inseparable | **no ge-** | verstehen → ich habe **verstanden** |
| no prefix | **ge-** in front | suchen → ich habe **gesucht** |

## Articles

| | masculine | feminine | neuter | plural |
|---|---|---|---|---|
| definite | **der** | **die** | **das** | **die** |
| indefinite | **ein** | **eine** | **ein** | – |

- Plural is always **die**: die Männer, die Frauen, die Häuser.
- Introduce with **ein/eine**, refer back with **der/die/das**: *Da vorne ist **eine** Bäckerei. **Die** Bäckerei hat gute Brötchen.*
- No indefinite article in the plural: *Da sind Kinder. **Die** Kinder spielen.*

## Gender by ending

The ending tells you the article most of the time. Plural is always **die**.

| der (masculine) | die (feminine) | das (neuter) |
|---|---|---|
| **-er** der Rentner | **-e** die Tasche | **-chen** das Mädchen |
| **-ling** der Schützling | **-t** die Fahrt | **-lein** das Kindlein |
| **-or** der Reaktor | **-ei** die Wäscherei | **-um** das Publikum |
| **-ist** der Journalist | **-ie** die Psychologie | **-nis** das Zeugnis |
| **-ismus** der Kapitalismus | **-in** die Prinzessin | **-tum** das Altertum |
| **-ant** der Praktikant | **-schaft** die Freundschaft | **-ment** das Instrument |
| **-ent** der Student | **-heit** die Gelegenheit | **-o** das Radio |
| **-ich** der Teppich | **-keit** die Schnelligkeit | **-ma** das Thema |
| **-ast** der Ballast | **-ung** die Zeitung | **-em** das System |
|  | **-ion** die Diskussion |  |
|  | **-age** die Garage |  |
|  | **-ur** die Agentur |  |
|  | **-ik** die Physik |  |
|  | **-anz** die Akzeptanz |  |
|  | **-tät** die Qualität |  |
|  | **-ade** die Parade |  |

**Ge-** at the start is usually **das**: das Gemüse, das Geräusch. Tendencies, not laws: der Name, der Junge, das Auge.
