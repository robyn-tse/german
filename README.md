# german

Personal German learning hub: lesson notes, vocabulary, grammar, and quick drills.
Built with Astro, deployed to GitHub Pages at <https://robyn-tse.github.io/german/>.

- `npm install && npm run dev` — dev server (with `--host` for phone testing)
- `npm run build` — validates `src/data/vocab.json` and builds the site
- New lesson materials go in `inbox/`; the processing procedure is in `CLAUDE.md`.
